
# 🎬 Netflix India Clone

A Netflix-inspired landing page built using **HTML and CSS** as part of my frontend web development learning journey.

## 📌 About the Project

This project recreates the look and layout of a Netflix India landing page. It helped me practise HTML structure, CSS styling, layouts, and responsive design.

## ✨ Features

- 🎥 Hero section with a background image
- 🔴 Navigation bar with logo and buttons
- 📧 Email signup forms
- 🔥 Trending section with numbered poster cards
- 💜 "More Reasons to Join" feature cards
- ❓ FAQ section using HTML `<details>` and `<summary>`
- 📱 Responsive layouts for different screen sizes
- 🦶 Footer with useful links

## 🛠️ Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- Google Fonts (Roboto)

## 📂 Project Structure

```text
Netflix-Clone/
├── index.html
├── style.css
└── assets/
    ├── logo.svg
    ├── background.jpg
    ├── img1.webp
    ├── img2.webp
    ├── img3.webp
    └── ...
```

*Note: The assets folder should contain all the images referenced in the HTML.*

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Make sure `index.html`, `style.css`, and the `assets` folder are in the correct locations.
3. Open `index.html` in your browser.
4. Explore the webpage!
